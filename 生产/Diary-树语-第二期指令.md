## 〇 这一期做完，你会看到什么

年轮页 →「树语」→ 那棵树上，**主干上多了三圈细细的环**（像箍）。

| 你干什么 | 会看到什么 |
|---|---|
| **鼠标移到某一圈上** | 那一圈**微微亮起来**，光标变成手型 |
| **点一下** | 那一圈**从主干上"抽"出来**、放大成一圈能看清的环带；环上分成一格一格（＝那个月的日子），**写过的日子亮着、没写的暗着** |
| **再点一下** | 收回去 |
| **点另一圈** | 前面那圈自动收回，这圈抽出来（**同时只开一个**） |
| **点空白处** | 全收回 |
| **一篇都没写过** | ✅ **照样能点** —— 环照样抽出来，里面全是暗格（这就是你要的"空库可点、显示空"） |

⭐ 三圈 = **那个季度的三个月**；一圈 = **一个月**；一格 = **一天**。

### A · 三圈长什么样

| # | 本来可以自己定 | **现在定成** | 为什么 |
|---|---|---|---|
| **A1** | 三圈是**上下排开**还是**同心套叠** | **上下排开**（沿着主干，一圈一层） | 你说了"三个区域**一样大**"。同心套叠的话外圈必然比内圈大 —— **跟你的话矛盾**。（我上一张图画的同心，是错的，以这份为准） |
| **A2** | 三圈各自多粗 | **一样粗**（半径相同） | 同上。实测主干从根到梢只收细 **22%**（`0.105 → 0.082`）⇒ 本来就几乎一样粗，做成一样粗不会显得假 |
| **A3** | 三圈在主干上的高度 | 沿主干 **15% / 40% / 65%** 三处 | ⚠️ 避开**侧枝着生点**（三层侧枝正好在 25% / 50% / 75%）—— 环压在枝根上会糊成一团。这三个位置正是**层与层之间**，间距各约 25% |

| **A5** | 平时看不看得见 | **看得见，但含蓄** —— 三圈细环贴在主干上，颜色只比树皮深一档 | ⚠️ **这条是有理由的**：你定过"界面上不写解释性小字"，那**唯一的提示只剩"看得见"** —— 完全隐身的话你根本不知道这儿能点 |

| **A7** | 点开后是什么形状 | **原地向外扩成一圈扁环带**（外径约 **2 倍**），像抽屉拉出来 | 项目书里那句"像**抽屉**一样抽出一圈年轮"就是它 |

## 四 批次 1 · **能点**（做完就停）

### 你会看到

树上主干**多了三圈细环**；鼠标移上去会亮；点一下会**扩开成空环**（这时还没有数据，格子全暗）；再点收回。

### 动手

1. **先把"三个环该在哪"写成能单测的纯函数**
   `💻` 新建 `app/src/tree/rings.ts`：**只做数学、⛔ 不 import three**。
   输入：主干的两个端点（从 `tree.branches[0]` 取，⛔ 不写死坐标）+ 三个月份号；
   输出：三个环的**中心点 / 朝向 / 半径 / 各自属于哪个月**。
   ⇒ 好处同第一期：**前端单测能直接守它**。
   ⚠️ **位置必须从真实主干坐标算** —— 主干长度带 ±5% 抖动，写死会对不准。

2. **建"点中哪根环"的拾取**
   `💻` 在 `tree/scene.ts` 里加：一个 `THREE.Raycaster` ＋
   `pickRing(nx, ny): number | null`（屏幕归一化坐标进去、环的序号出来）。
   ⚠️ **拾取对象不是环的网格本身**，而是**每个环一个"看不见的粗圆柱"**（半径比主干大一圈）
   —— 环是细的，直接点细环**会点不中**；用粗圆柱包住，手感才对。
   ⛔ 圆柱必须 `visible = false` 但**参与拾取**（`Raycaster` 默认会跳过 `visible=false`，
   要用单独一个数组来 `intersectObjects`，别去翻全场景）。

3. **画环**
   `💻` 在 `tree/scene.ts` 里加：三圈细环（`TorusGeometry` 或一个薄圆环面片）
   ＋ 展开态的环带（外径 2 倍、可分成 N 格）。
   ⚠️ **平时态和展开态是两套几何体**（细环 / 宽环带），⛔ 不要靠缩放同一个东西变出来
   —— 缩放会把环也拉粗，形状会走样。
   ⚠️ 颜色**一律走 CSS 变量**（老铁律），深浅主题各一套。

4. **接指针事件**
   `💻` 在 `TreePane.vue` 里：`pointermove` → 算出归一化坐标 → `pickRing` → 决定"亮哪一圈"；
   `pointerdown/up` → 判定是"点击"（不是拖动）→ 切换展开/收回。
   ⚠️ **要区分"点击"和"拖拽"**：位移超过几个像素就当作拖拽、不触发展开。
   ⚠️ 光标变成手型只能改在**画布的 CSS** 上（`canvas.style.cursor`）。

5. **状态写到验收钩子上**
   `💻` `window.__treeStage` 加几个字段（沿用第一期那个钩子）：
   `ringCount` / `ringRadii` / `ringPositions` / `ringOpen` / `ringHover` / `ringPickHits`。

| **1** | **`Raycaster` 默认跳过 `visible = false` 的对象** | 想用"看不见的粗圆柱"当热区，就得把圆柱放进**单独一个数组**去 `intersectObjects`，⛔ 别指望 `intersectObjects(scene.children, true)` 帮你找 |
