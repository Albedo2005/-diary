## 四 第一期指令

> 分**三批**给你看（你说"不要求一步到位"）—— 每批做完停下，你点头再往下。
> 每步里的 💻 块是**技术细节，可以整段跳过**。

### 批次 1 · **探针**（必须先做；做砸了，整条路都得重来）

**目的**：验证「**3D 到底能不能在你的软件里跑起来**」。
整条路线赌在这一步 —— WebView2 不等于是浏览器，有极小概率白屏或画不出来。

**你会看到**：年轮页里多一个临时的「树语」tab，点进去是一个**转着的方块**。

- 装 `three`；
- 临时加 tab，放一个最简单的场景（一个转动的方块 ＋ 一块地面）；
- **亲眼看**：方块在转、颜色正常、不闪不白屏；
- 自动检查四件事：① 画面真的在刷新（帧数在涨）② **切走之后真的停了**（帧数不再涨）③ 截图解码确认不是白屏也不是黑屏 ④ 控制台没有报错。

> 💻 **技术（可整段跳过）**
> - 装法：在 `app/` 下 `npm i three@0.186.1` ＋ `npm i -D @types/three@0.186.0`；
> - 验证走 `tauri-webview2-ui-verify` 技能：起 exe 带 `--remote-debugging-port`，
>   用 CDP 断言 `canvas` 尺寸 > 0、渲染帧计数递增、`tab` 切走后计数冻结、截图**解码像素**（⛔ 不信看图预览）；
> - ⚠️ 起之前先清掉残留的本应用 WebView2 进程树，否则调试端口会**静默失效**。

⭐ **停靠点 1**：这一步做完**立刻停下来告诉你结果** —— 能跑才继续。

### 批次 2 · **台子 ＋ 一棵树**

**你会看到**：**第一棵真的树**（先给截图）。

**第 1 步 · 搭台子**
- 树语 tab 从"临时"变成"正式"：一整屏画布，跟着窗口大小变；
- 相机、光照（天光 ＋ 一束**带阴影**的直射光）、地面、一层很淡的雾；
- 天空**先给纯色/渐变底**（真正的天空是第四期的事）。

**第 2 步 · 长出树**
- **参数化生成**：树干 → 分叉 → 再分叉，深度可控；**形态固定下来**（每次打开是同一棵，不跳）；
- 枝干材质做出"木头"质感；**树皮贴图用代码算出来，不下素材**；
- ⚠️ 性能：几百根枝条要**合起来一次画**，不能画几百次。

> 💻 **技术（可整段跳过）**
> - 递归分枝：角度 ±（15~25°）、长度比 0.7 左右、深度 **≤ 8**（`2^8 = 256` 条，出处实测"深度 15 就明显卡"）；
> - 几何合并用 `BufferGeometryUtils.mergeGeometries`，或干脆 `InstancedMesh`；
> - 贴图用 `CanvasTexture` 程序化生成（噪声／年轮环）；**随机数一律先算一次再喂给着色器**，
>   ⛔ 绝不每帧在主线程改样式；
> - 视角第一期**固定**，不引 `OrbitControls`（"能转"是第二期的事，早引只会白增体积）。

⭐ **停靠点 2**：给你看截图 —— **"像不像、够不够好看"，你说了算**。觉得不对就停在这儿调，不往下走。

### 批次 3 · **花与叶 ＋ 风 ＋ 纪律 ＋ 验收**

**你会看到**：树上有花有叶，会随风轻摆；**切走就停**。

**第 3 步 · 花与叶**
- 枝头挂花和叶（这一期**数量固定/随机**，⛔ 先不接你的日记数据）；
- 叶子用带透明边的面片，**一次画几百片不卡**的做法；
- 花的颜色照画风锚点调（按第 3 件拍板：春樱 / 当季 / 只带叶）。

**第 4 步 · 风**
- 枝条轻摆 ＋ 花叶微动；风的大小是一个参数，风大摆得狠；
- ⚠️ 摆动的计算**放在显卡里**，**不在主线程上算** —— 这是"风扇不吵"的关键。

**第 5 步 · 停下来会呼吸**（纪律，必须全做完才算完）

| 规矩 | 为什么 |
|---|---|
| 切走这个 tab ⇒ **立刻停** | 否则你写一整天日记，风扇就转一整天 |
| 软件切到后台 ⇒ 停 | 同上 |
| 系统里"减弱动态效果"开着 ⇒ 静态 | 跟你之前那条口径一致 |
| **界面上有一个你能找到的开关** | ⛔ 不能只藏在系统设置里 |
| 画质按屏幕密度**封顶** | 高分屏上别傻乎乎地按 4 倍画 |
| ⛔ 花叶**永远不出现在写日记 / 搜索 / 筛选页** | 有输入框的地方飘东西是干扰 |

**第 6 步 · 验收**
- 自动检查：画面在动 / 切走会停 / 不白屏 / 不报错 / 帧时间在预算内；
- 截图给你看；
- **顺带量一次安装包到底大了多少**，把实数填回本文档第三节。

⭐ **停靠点 3**：第一期交付。你点头 ⇒ 开第二期；不点头 ⇒ 就地调，不欠账。

## 五 怎么验收（沿用老规矩）

| 项 | 做法 |
|---|---|
| **验收对象** | **发布件本身**（不是开发模式下的窗口） |
| **界面行为** | 走 `tauri-webview2-ui-verify` 技能（CDP 驱动真实 DOM ＋ 截图解码像素） |
| **"没发生"的断言** | 必须**配一条"能发生"的对照**（否则"没动"可能只是没跑到） |
| **动效判据** | 与帧率 / 系统设置**无关**：跑前显式把 `prefers-reduced-motion` 设成 `no-preference` |
| **性能** | 记帧时间，不写"感觉流畅" |
| **证据归档** | `生产\交付证据\树语-第1期\`（验收脚本 ＋ 结果日志 ＋ 截图 ＋ README，README 第 3 行记提交哈希） |
