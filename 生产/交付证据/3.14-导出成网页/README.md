## 二、想复跑一遍怎么做

```bash
cd D:\Users\Lenovo\Desktop\Diary\生产\交付证据

# 验收（约 3 分钟；结果打到屏幕）
node 验收脚本.cjs

# 冒烟
node 冒烟脚本.cjs
```

- 想指定别的 exe：先 `set DIARY_EXE=D:\...\app.exe`
  （⛔ 但**正式验收必须钉在 `发布\日记.exe` 上**：`tauri build` 与裸 `cargo build`
  的产物字节数可能不同 ⇒ 验过的那个必须等于用户拿到的那个）。
- ⚠️ **开跑前先关掉正在运行的日记**：残留的本应用 WebView2 进程会让调试端口**静默失效**
  （症状是连不上，不是报错）。
- ⚠️ **脚本自己会清两样东西**，别去掉这两步：
  ① 一次性数据目录（留着旧库 ⇒ 开屏走「解锁」、成片假红）；
  ② **`localStorage`** —— 它**不在**一次性数据目录里（活在 WebView 用户数据目录），
     光删数据目录清不掉它，上一轮的界面偏好会让这一轮的「开局前提」全错。
- 脚本内部：`ROOT` 仍指向仓库根的 `_ui-verify-314\`（写临时数据用），
  `PORT = 9384`，`EXPECT_VERSION = "3.14"`。

## 三、上一轮红过一条 —— 留个记录

第一轮跑出来 `163 条、失败 1 条`，红的是 **N.24**，而且**打印出来的正文恰好就是期望的那串**。
根因：**脚本自己切片少算了 5 个字符**（从 `class="content"` 切、而不是从 `<div class="content">` 切）。
⇒ **不是产品问题，是脚本问题**。改法：

```js
const divAt = exHtml.indexOf('<div class="content">');
const exBody = divAt >= 0 ? exHtml.slice(divAt) : "";
```

> 教训：断言失败时**先读它打印出来的实际值**。实际值等于期望值 ⇒ 先怀疑自己的取数逻辑，
> 别急着去改产品代码。
