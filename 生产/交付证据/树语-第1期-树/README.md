## 七、这一批踩到的坑（已写进生产日志坑表）

### 1. ⭐⭐ **假绿**：画布撑破了容器、树被裁到右下角只剩一角 —— 而 **44 条断言全绿**

**症状**：截图里整片天空，树只在右下角露出一小块。

**根因**：`renderer.setSize(w, h, false)` 的第三个参数是"**不要往画布上写内联宽高**"，
而 `display: block` 单独**不会**给 `<canvas>` 一个 CSS 尺寸 ⇒
画布退回去拿**背衬尺寸**当自己的显示尺寸（＝可用宽 × 屏密度 ＝
**785 × 1.875 ＝ 1471px**），于是撑破 785px 的格子，被 `overflow: hidden` 裁掉。

**为什么 44 条断言全绿**（两处都得记）：
- **C3 写松了**：原来写的是"画布宽 **≥** 可用宽 − 2" ⇒ `1471 ≥ 785` **通过**。
  正确的写法是"**差的绝对值 ≤ 2**" —— **不是"至少"，是"等于"**。
- **所有像素断言只问"这一行有没有东西"，从不问"东西在哪"** ⇒
  树被推到角上，每一行照样"有起伏"。

**修法（三处一起）**：① CSS 给画布补 `width/height: 100%`；
② C3 从 `>=` 改成 `Math.abs(差) <= 2`；③ **新增** C5/C6/F9/F10/F11 —— 专门审"在哪"。

### 2. ⚠️ **`selfTest` 不能只是"说要有"**

批次 1 的脚本头部承诺了要有 selfTest，**但一个字都没写**。
这一版补上：用**人造图 + 已知答案**先把量尺子校准，再拿它去量真图。
⭐ 上面的坑 1 里，**F9/F10/F11 用的是同一批函数** —— 尺子不校，绿就是自我印证。

### 3. ⚠️ **注释里写 glob 会提前闭合块注释**

`grow.ts` / `tree.test.ts` 的文档注释里写了 `"tests/**/*.test.ts"`，

### 4. ⚠️ **exe 里查不到字符串 ≠ 资源没进去**
