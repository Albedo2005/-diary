## 六 红线（⛔ 一条都不许碰）

- ⛔ **不动后端**：Rust 一行不改、不加依赖、不动数据库、不动存储格式；
- ⛔ **不动老日记**的任何一个字；
- ⛔ **不动写日记 / 搜索 / 筛选 / 刻度 / 旧影**的功能与外观；
- ⛔ **中途不动版本号**（第一期整个交付完再统一走版本流程）；
- ⛔ **不顺手重构**别的代码；
- ⛔ **3D 跑不起来不许偷偷降级成 2D**（见 E4）；
- ⛔ **界面里不写解释性小字**（唯一例外仍是"安全事实"）。

## 七 注意事项 / 坑表（动手前先读一遍）

| # | 坑 | 怎么防 |
|---|---|---|
| **1** | **残留的 WebView2 进程会让调试端口静默失效** | 每次起 exe 前**先清那棵树**；⛔ 别误杀系统 webview |
| **2** | **`localStorage` 不活在数据目录里** | 开局除了换一次性数据目录，**还要显式删本应用的 `localStorage` 键**再 reload |
| **3** | **验截图颜色** | 一律**解码像素**问，⛔ 不信看图预览（老规矩） |
| **4** | **"没发生"的断言必须配"能发生"的对照** | 比如验"切走会停"，必须先证明"不切走时会涨" |
| **5** | **动画判据要与帧率 / 系统设置无关** | 跑前显式设 `prefers-reduced-motion: no-preference`（本机"减弱动态效果"是**开着**的） |
| **6** | **CDP 的 `send` 必须带超时** | 应用一退 WS 会**静默关闭**，不带超时的 Promise 永不结束，脚本会以 **0**"正常"退出（假绿） |
| **7** | **three 的打包体积** | `vite build` 后核对产物大小；⚠️ three 出了名地"裁不干净"，若涨得离谱先记下来、别硬裁 |
| **8** | **`vite build` 全绿 ≠ 产物新** | 核对 **modules transformed** 那个数；判据是"这版该不该变" |
| **9** | **长短不一的随机值别每帧算** | 随机数**只算一次**塞进材质/属性里 |
| **10** | **别给所有材质加"预编译"开关** | 只有花叶那种大量实例才需要 |
| **11** | **`cargo` 那套本功能用不上** | 这一期**完全不碰 Rust**，⛔ 不要顺手跑 cargo（白等 15 分钟） |
| **12** | **前端单测** | `💻` Node 22 原生跑 `.ts`；⚠️ ESM **不认无扩展名的相对路径**（要写 `from "./x.ts"`） |
