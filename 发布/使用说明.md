# 怎么运行

双击 **`日记.exe`** 即可。

首次启动会让你设置一个 6 位数字密码。以后每次打开都要输入这个密码 ——
日记内容在硬盘上是加密的，没有密码谁也读不出来（包括你自己，所以别忘）。

> **本文档对应 `2.6` 这一版**：P0 十项基础功能 ＋ P1 六项（标签、心情、统计、
> Markdown 导出、图片附件、修改密码）全部完成；之后图片的用法又改过两轮
> （`2.2` 试过"图片长在正文里"，`2.3` 定成"图片只挂在这一天"），
> 日历加了快速跳转、又加了"年份可以直接打字跳"，设置里又加了
> **"离开日记时自动锁定"开关**（不想让切日期就自动上锁的话，可以去关掉它），
> 锁定后还可以**在正文里连点三下左键直接解锁**（手不用移到右上角）。
> 下面写的就是现在这个版本的样子。
>
> ⚠️ **设置 →【关于】里显示的"版本号"是 `0.1.0`，那不是错的** —— 它是程序**自身**的
> 编号字段，一直没动过。本项目对外用的是**阶段号**（P0 = `1.x`、P1 = `2.1`、P2 = `3.x`），
> 记在项目的 `生产日志.md` 里。**想确认手里这份是哪一版，别数号**：
> 看 `日记.exe` 的文件大小或 sha256，产物表里一份一份都列着。

## 两个文件的区别

| 文件 | 说明 | 什么时候用 |
|---|---|---|
| **`日记.exe`** | 免安装，双击就跑 | **推荐**。想用就直接双击这个 |
| **`日记-安装程序.exe`** | 安装到系统，生成开始菜单/桌面快捷方式 | 想让它像普通软件一样出现在开始菜单里 |

`日记.exe` 是完整程序，不需要先运行安装程序。

## 第一次使用

1. 双击 `日记.exe`
2. 设置 6 位数字密码（**建议写一个提示**，忘了密码真的找不回来）
3. 点日历上任意一天，开始写
4. 输入停止约 1 秒会自动保存

## 界面速览

顶栏是三个并列的视图，加右边两个按钮：

| 位置 | 是什么 |
|---|---|
| **写日记** | 打开软件默认落在这里。左边日历、右边正文 |
| **搜索** | 全库搜中文，结果点一下直接跳到那天的日记 |
| **统计** | 共写了多少篇 / 最长连续多少天 / 本周本月 / 心情分布 / 每月字数 |
| **设置** | 一个弹窗：左栏分类（安全 / 数据与备份 / 关于），右栏内容 |
| **锁定** | 把当前这篇锁成只读（见下面「锁定」一节） |

顶栏最右边还有一行小字「共 N 篇 · 连续 M 天」，抬眼就能看到进度。

### 写日记

**自动保存**：正文、标题、标签、心情，改动后约 1 秒自动落盘，没有"保存"按钮。
左下角会有一行小字告诉你上次保存的时间。

**图片**：三种插法 —— 标题行右边的 **🖼 插入图片**、**直接把图片拖进来**、
**Ctrl+V 粘贴**（截图之后直接粘，最省事）。

- 支持 `png` / `jpg` / `jpeg` / `gif` / `webp`，**单张最大 20 MB，一篇最多 50 MB**
- 图片**只挂在这一天上**，显示在正文上方那排缩略图里 —— **正文永远只有你自己打的字**，
  不会插进任何图片语法或文件名
- 粘贴进来的截图会自动起个名字（形如 `粘贴-20260921-164312.png`）
- **点缩略图 → 放大**；放大之后按 **← →**（或点左右那两个圆按钮）翻上一张 / 下一张，
  底下那行小字会写着"第 3 / 7 张"
- 缩略图默认只占**一行**：图多了，那一行最右边会出现一个 **⌄** 折叠按钮，
  点开铺满、再点收起
- 点缩略图右上角的 `×`，把这张图从这篇里删掉（记录和文件一起删）
- 图片是**跟着数据目录走的**，整个 `Diary` 文件夹复制到别的电脑，图还在
- ⚠️ **图片不加密**（正文加密、图片不加密）—— 详见下面「关于图片的实话」

**标签**：正文下方一行标签。点 **＋** 弹出面板：

- **常用** 是一批预设标签，点一下就用上（预设本身不占数据库，只有你真用了才存下来）
- **其他** 是你自己敲过的标签；每个后面有 `×`，可以就地删除（**不会影响已经写过的那天**）
- 底部有输入框，可以直接新建

一篇日记能贴多个标签。标签是"这篇写了什么主题"，**心情**是"这一天整体怎么样"，两套分开。

**心情**：标签上方一行五个表情，点一下就标上，再点一下取消。
五档是**并列**的分类，没有好坏强弱之分：

| 😭 悲伤 | 🤕 受伤 | 😶‍🌫️ 茫然 | 😡 愤怒 | 🥰 开心 |
|---|---|---|---|---|
| 1 | 2 | 3 | 4 | 5 |

不标也行（不标 = 未标记）。

**标题**：正文上方那一行。标题只影响显示，**不会**参与搜索正文的匹配。

### 日历

左边那块日历是本月的总览：**写过的日子带圆点**、**今天带个框**、
**标过心情的日子右上角有小表情**。

- 换月份：标题两边的 **‹ ›** 一次挪一个月；**点标题**则弹出年月面板 ——
  上面 **‹ 2026 年 ›** 直接跳年（**年份能一路翻到 `1949 ~ 2099`**，走到两头箭头会变灰，
  不会无限翻下去），下面 12 个月，点哪个跳哪个
- **想直接去某一年**：点中间那个年份（`2026 年`）它就变成输入框，**打进年份、按回车**就跳过去
  （键盘上的数字会被自动全选，直接打就行）。范围还是 `1949 ~ 2099`，**打成这个范围外的数字
  会自动夹到最近的一头**（打 1800 → 跳到 1949；打 3000 → 跳到 2099）；
  ⚠️ **只有按回车才算数** —— 打到一半去点箭头或点月份，那半截数字会被丢掉、年份还是原来的
- 面板底部三个快捷入口：**今天** / **第一篇**（最早写过的那天）/
  **最近一篇**（最近写过的那天）。还没写过任何日记时，后两个是灰的
- ⚠️ 在面板里换月份**只换"看的是哪个月"**，右边正文还停在你原来那天；
  只有底部那三个入口会连正文一起跳过去
- 面板按 **Esc** 或点别处就关掉

### 搜索

在「搜索」视图里输入关键词，回车。结果里点任意一条，直接跳到那天的日记。

约 1~2 个字的短词也能搜到（背后做了两套索引）。

### 统计

「统计」视图里能看到：

- **共 N 篇** —— 和导出时的篇数**严格一致**（都是"真正写过的那几天"）
- **当前连续 / 最长连续** —— 今天还没写、昨天写了，照样显示"截至昨天"，不会归零
- 本周 / 本月写了几天、每月字数、心情分布

> 面板上的日期**一律带年份** —— 因为这里画的可能是跨年的区间。

### 锁定

- 锁定 = 这篇**只读**：不能改正文、不能删、不能改标签和心情
- **锁定不动你的排版**。你手敲的换行、空格、缩进原样保留
  （早先这里是个"阅读"按钮，会把正文当 Markdown 渲染，把你排的版吃掉。已经删掉了）
- 锁定状态**每篇各自记住**，下次打开还是锁着的
- **切换日期**或**关掉软件再打开**时，所有日记会**自动全部锁上**。
  所以平时看到的就是"锁定"状态，想改的时候点一下解锁再改。
  （这条**可以在设置里关掉** —— 见 设置 →【安全】→ 离开日记时自动锁定）
- **解锁有两条路**：点编辑器右上角那个 🔒 按钮；或者在**正文里连点三下左键** ——
  手不用离开正文（这条也可以关，见 设置 →【安全】→ 三击左键快速解锁）。
  ⚠️ 三击**只在锁定状态**下才有这个作用；没锁的时候，连点三下就是浏览器原本的
  "选中一整段"，既不会解锁也**不会**把日记锁上，不用担心误触。

**另外还有一道"离开自动锁定"**：窗口失去焦点后，按你设定的时长清除内存里的密钥，
到点就自动锁上。时长在 设置 →【安全】→ 自动锁定时长 里调：**1 / 5 / 10 分钟 / 永不**，
默认 **10 分钟**。

## 设置里有什么

### 【安全】

| 项 | 说明 |
|---|---|
| **修改密码** | 改成新密码。⚠️ 改之前产生的**备份仍要用旧密码打开** —— 重新加密只作用于主库，备份文件不会被改动（那正是备份的意义）。换完会自动备份一份**新的**，那一份用新密码 |
| **免密打开** | 打开，勾选后双击 `日记.exe` **不用输密码**直接进。（开启和关闭**都要输一次密码** —— 否则任何人趁你屏幕还亮着点两下，就能把它变成永久免密入口。）⚠️ 开启后，解锁用的钥匙会以**明文**存在 `data/auto_login.json` 里 —— 见下面「已知限制」 |
| **自动锁定时长** | 1 / 5 / 10 分钟 / 永不。见上面「锁定」一节 |
| **离开日记时自动锁定** | 勾选（默认）：切到别的日子、或重开软件时，**自动把写过的日记锁上**，防止误删误改。去掉勾：切回来仍然可以编辑，不用反复点解锁；想锁时点右上角 🔒。⚠️ 它和上面那条**不是一回事** —— 上面锁的是**整个软件**（回密码页），这条锁的是**单篇日记**。⚠️ 取消勾选**不会**把已经锁上的日记解开 |
| **三击左键快速解锁** | 勾选（默认）：日记锁定时，把光标放进正文**连点三下左键**就解锁，手不用移到右上角。去掉勾：只能用右上角 🔒 按钮解锁。⚠️ 它只管"这个手势要不要开" —— 取消勾选**不会**把已经锁上的日记解开；不管开不开，🔒 按钮都照旧好用 |

### 【数据与备份】

| 项 | 说明 |
|---|---|
| **每天自动备份** | 开关。对日记来说，"忘了开备份"等于"没有备份"，建议开着 |
| **立即备份** | 现在导出一份**加密**副本（默认在 `backups\` 里；下面会显示已有几份、下次自动备份什么时候） |
| **导出全部日记** | 把全部日记导出成 **Markdown**（明文）：`index.md` ＋ `年/月/日期.md`，任何编辑器都能读。与「立即备份」正好是一对：备份是**密文**、防丢；导出是**明文**、防被这个软件锁死。⚠️ 导出是明文的，别导到网盘同步目录里 |
| **图片缓存** | 显示图片存在哪、可以打开那个文件夹，以及一个**清理图片缓存**按钮 |
| **检查索引一致性** | 核对搜索索引和正文对不对得上，对不上会自动重建。平时不用点 |

**「清理图片缓存」是干什么的**：删掉一篇日记时，它的图片**不会**被立刻删掉
（数据库只清记录，磁盘上的文件留着）。点这个按钮会做两件事：

1. 表里有记录、但磁盘上文件已经没了的 → 删掉那条死记录
2. 磁盘上有文件、但已经没有任何日记在引用的 → 删掉文件，并告诉你释放了多少空间

它**只动数据目录里的 `attachments/` 这一个文件夹**，而且是手动点的，不会在后台乱删。

### 【关于】

只读信息：版本号、数据目录位置、加密参数（Argon2id 的内存与迭代次数）。

## 数据存在哪

```
Diary\
    data\
        diary.db            你的日记（加密）
        crypto_meta.json    解密所需的 salt 与参数
        lockout.json        密码错误次数与锁定状态
        auto_login.json     免密打开开启时才有（明文，见「已知限制」）
        attachments\        图片附件（不加密）
             <sha256>.png   文件名是内容算出来的，所以同一张图只存一份
```

数据跟着程序走：程序会从自己所在的位置往上找 `data` 文件夹，
所以整个 `Diary` 目录复制到别的电脑上，日记还在（图片也是）。

## 备份和导出，别搞混

|  | 立即备份 | 导出全部日记 |
|---|---|---|
| 产物 | 两个文件（`diary-*.db` ＋ `diary-*.meta.json`） | 一堆 `.md` 文件 ＋ 一个 `index.md` |
| 是明文吗 | ❌ 加密，还得用本软件打开 | ✅ 明文，记事本就能看 |
| 用途 | **防丢**（硬盘坏、误删） | **防被这个软件锁死** |

⚠️ 备份**两个文件都要留着** —— 少了 `meta` 文件，即使密码正确也打不开。

## 关于图片的实话

**图片不加密，正文加密。**

这是有意为之（图片加密后再交给界面显示，工程量大得多），但后果必须说清楚：

- 图片是**明文**躺在 `data\attachments\` 里的
- 如果有人翻你的硬盘，**图片能直接看**
- 如果你把 `Diary` 文件夹放进网盘同步目录，**图片会被传上去**，
  于是出现"正文是加密的、图片却明文躺在云盘里"的错觉
- 所以：**真正敏感的图片不要往里放**

## 密码相关的两点实话

**1. 密码只有 5 次机会，错 5 次锁 10 分钟。**

**2. 忘记密码 = 数据永久丢失。** 这不是设计缺陷，是加密的必然结果：
密钥由你的密码推导出来，程序里不存任何能帮你找回的东西。

另外要说清楚：锁定期只能限制"在这个程序里试"，挡不住有人把数据库文件
拷走、在别的程序里暴力破解。真正防这道的是 Argon2id 的高内存开销
（每个密码候选都要占 512 MB 内存、算约 0.8 秒）。

**它挡得住的是**：翻你电脑的室友、同事、家人。这是绝大多数人真正的威胁。

## 已知限制

- 只能 Windows 上运行
- **图片附件不加密**（见上）
- **免密打开开启后，`data\auto_login.json` 是明文钥匙** ——
  省事的代价。别人把这个文件拷走就等于拿到了钥匙，所以别开免密来防"懂电脑的人"
- 编辑时看到的就是 Markdown 源码本身，排版由你自己敲的换行和空格决定（不渲染成 Word 那样）。
  **图片不渲染进正文** —— 它挂在"这一天"上，显示在正文上方那排缩略图里
- 只能一天一篇，还不能建多个日记本
- 导出目前只有 Markdown；HTML / PDF 还没做

## 开发者：怎么直接运行（不用每次打包）

打包（生成安装程序）只在要发给别人时做。平时改完代码有两种跑法：

**① 开发模式 —— 改代码界面立刻变，最快**

```powershell
cd D:\Users\Lenovo\Desktop\Diary\app
pnpm app:dev
```

**② 编译成可直接双击的 exe —— 不生成安装程序**

```powershell
cd D:\Users\Lenovo\Desktop\Diary\app
pnpm app:exe
```

产物在：

```
D:\Users\Lenovo\Desktop\Diary\target\release\app.exe
```

双击就能跑，和平时的 `发布\日记.exe` 是同一个东西 ——
区别只是**没有**生成安装程序。（`--no-bundle` 也跳过了重命名那一步，
所以文件名是 `app.exe` 而不是 `日记.exe`，这是正常的。）

**改完功能、要刷新 `发布\日记.exe` 时**（构建 + 复制 + 冒烟，一条命令）：

```powershell
powershell -File D:\Users\Lenovo\Desktop\Diary\scripts\publish-exe.ps1
```

**要发安装包时才跑**（打包 + 安装程序）：

```powershell
cd D:\Users\Lenovo\Desktop\Diary\app
pnpm tauri build
```

产物才会是 `target\release\日记.exe` 和 `日记-安装程序.exe`。

**跑测试**：

```powershell
cargo test -p app
```

> 注意：上面这些依赖 `scripts\env.ps1` 里的构建环境（cargo、perl、nasm、make）。
> 如果提示找不到 cargo，先在 PowerShell 里执行
> `. D:\Users\Lenovo\Desktop\Diary\scripts\env.ps1`。
>
> ⚠️ **不要跑 `cargo test --release`** —— 工作区设了 `panic = "abort"`，
> 与测试框架不兼容，必然失败（原因见 `生产日志.md` 的坑表）。
